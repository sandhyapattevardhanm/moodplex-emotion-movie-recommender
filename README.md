# 🎬 MoodPlex — Emotion Based Movie Recommender

MoodPlex is an AI-powered movie recommendation system that detects a user's emotion from text input and recommends movies based on their mood.

Built using:
- TensorFlow / Keras
- NLP
- CNN-based Emotion Detection
- Streamlit
- Content-Based Movie Recommendation

---

# ✨ Features

- Detects emotions from natural language text
- Supports:
  - Joy
  - Sadness
  - Love
  - Anger
  - Fear
  - Surprise
- Recommends movies based on detected mood
- Interactive modern Streamlit UI
- Content-based movie recommendation system
- Real-time predictions

Python · TensorFlow/Keras · Scikit-learn · Pandas · Streamlit
